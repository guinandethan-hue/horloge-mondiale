    À propos

    Horloge mondiale permet de comparer les heures à partir d’un pays, d’un fuseau et d’une date de référence. Le bouton de l’appareil utilise le fuseau configuré dans le système, sans demander de position GPS.

    Les calculs des fuseaux IANA utilisent les règles disponibles dans le navigateur ou dans Electron. Une mise à jour de l’application peut être nécessaire lorsque ces règles changent. Les dates proposées vont de 1970 à 2100 ; les règles futures peuvent évoluer.

    Les frontières des pays et des fuseaux sont simplifiées. Une zone possédant seulement un décalage UTC fixe ne permet pas de calculer automatiquement ses changements d’heure : ce cas est indiqué dans le panneau d’information.

    Les couleurs représentent l’écart avec la référence : bleu pour une heure en retard, gris pour le même décalage, orange pour une heure en avance. Les dates restent importantes, notamment près de la ligne de changement de date.

    Bibliothèques et données : Leaflet, world.geo.json et Natural Earth. La carte utilise uniquement les fichiers locaux du projet : aucune clé API ni connexion n’est nécessaire pour l’afficher.
